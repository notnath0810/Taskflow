# Taskflow

Building a CRUD Web Application with Database Integration

Student pairs are required to develop a simple web application (e.g., Student Record System, Task Manager, Inventory System, or similar) of their choosing that interacts with a database and performs CRUD operations. Please verify between your peers that the application that your pair are making must be different from the other groups/pairs.

Students must perform the following objectives:

Design and implement a simple web-based application
Create a user interface using HTML, CSS, and JavaScript
Perform CRUD operations (Create, Read, Update, Delete)
Connect a web application to a MySQL database using PHP and XAMPP
Documentation that must be included in this assessment:

Use Case Diagram
Wireframe and UI/UX Prototype (Stitch or Figma)
Entity-Relationship Diagram
System Requirements

User Interface (Frontend)
Create a functional interface using:
HTML – for structure
CSS – for styling
JavaScript – for interactivity
The application must include forms for data input and edit, and the interface should be user-friendly and organized. Include a page that retrieves and displays relevant data from the database. Find a way to rearrange the said data in two ways (of your choice) base on a specific column(s) selected.
Database Design (MySQL)
Create a database using phpMyAdmin and the necessary tables applicable to your application

Backend Development (PHP)
Use PHP to connect to the MySQL database in order to process form data and execute SQL queries. The pair must implement the following CRUD operations:
Create – Insert new records into the database
Read – Display records in a table format
Update – Modify existing records
Delete – Remove records
Suggested File Structure

/project-folder <-- name of project application
│── index.php
│── dbconfig.php
│── insert.php
│── update.php
│── delete.php
│── style.css
│── script.js
